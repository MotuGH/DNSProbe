# DNSProbe

Локальная диагностика DNS для Windows x64: UDP, TCP, DoT, DoH, DoH3 и DoQ. Собственная серверная инфраструктура не требуется. Интерфейс на русском языке открывается в браузере; запросы выполняет локальное приложение на Go.

## Запуск

1. Скачайте Windows ZIP из Releases и распакуйте в доступную для записи папку.
2. Запустите `DNSProbe.exe`. Откроется http://127.0.0.1:8765.
3. Выберите резолверы, домены и протоколы. Нажмите «Начать диагностику».

Повторный запуск открывает работающую копию. `dnspyre.exe` нужен рядом для нагрузочного режима. Закрытие браузера не останавливает приложение: для выхода закройте его консоль. Права администратора и установка Go для готовой сборки не нужны. Настройки DNS Windows не изменяются.

## Возможности

- Каталог 40 профилей DNS с источниками, поиск, алфавитный порядок и собственные серверы.
- Проверка TLS, соответствия ответа запросу и локальная проверка положительных DNSSEC-ответов до корневых якорей IANA.
- DoH3 и DoQ без автоматического переключения на другой протокол.
- Повторные измерения, задержка p95, серии ошибок, остановка, экспорт JSON.
- Автосортировка по доле ошибок и подозрительных ответов, затем по задержке.
- Локальная история с датой и временем проверки.
- Нагрузочные тесты через dnspyre 3.12.0: 1–100 QPS, 1–300 секунд.

## Ограничения

Это экспериментальная диагностическая утилита. Таймаут не доказывает цензуру, а разные адреса CDN не доказывают подмену. Smart DNS и фильтрующие резолверы могут намеренно менять ответы. Поддержка транспорта в каталоге не гарантирует доступности из каждой сети.

DNSSEC: реализована проверка положительных A/AAAA/CNAME. Отрицательные NSEC/NSEC3-ответы, wildcard, DNAME и доказательство unsigned-делегирования полностью не проверяются: результат остаётся неопределённым. Флаг AD сам по себе не считается подтверждением. Якоря IANA зафиксированы в исходниках (20326/38696); будущая ротация потребует обновления.

Задержка измеряется на свежих соединениях, без времени служебных DNSSEC-запросов. Для шифрованных DNS используется заданный bootstrap IP или системное разрешение имени. Нагрузочный режим dnspyre использует системное разрешение имени, поэтому его сетевой путь может отличаться.

История хранится в `history` рядом с EXE. Приложение не отправляет её в облако. Проверяемые домены передаются выбранным DNS-операторам. API доступен только на IPv4 loopback, POST защищены токеном и проверкой Origin.

## Сборка

Требуется Go 1.26 или новее; Node.js нужен только для проверки сортировки.

```powershell
go mod download
go test ./...
go vet ./...
node ranking_test.cjs
go build -trimpath -o DNSProbe.exe .
```

Тесты QUIC поднимают временные серверы на loopback: локальные UDP-соединения должны быть разрешены. Живые проверки отключены по умолчанию. `web/` и `catalog.json` встраиваются в EXE: после изменений нужна пересборка. Сборка предназначена для Windows.

Для нагрузочного режима скачайте официальный `dnspyre.exe` 3.12.0 из https://github.com/Tantalor93/dnspyre/releases/tag/v3.12.0 и положите рядом. Не требуется для обычной диагностики.
